# SKTJF tools

鶴岡高専の時間割PDFを確認・修正し、SKTJFの配信データを作成するためのローカルツールです。現在は編集画面の開発途中で、SKTJFの検証・出力や配信にはまだ対応していません。作業ファイルを配信データとして公開しないでください。

## 起動

Node.js 22以上を用意し、このディレクトリで次を実行します。

```sh
npm ci
npm start
```

表示された `http://127.0.0.1:4173/` をブラウザーで開きます。サーバーはローカルからのみ接続を受け付けます。PDFと編集内容はブラウザー内で処理します。

## 編集

1. PDFを開き、授業または日付を選びます。
2. 「セルを追加」を選び、PDF上をドラッグして範囲を指定します。
3. セルを選択して内容を入力し、必要に応じて範囲内の文字を抽出します。
4. 元のPDFと照らして確認し、確認が必要な点を解決してから「確認済み」にします。
5. 「作業を保存」でPDFを含む作業ファイルを保存できます。「作業を開く」で続きから編集できます。作業ファイルにはPDF原本が含まれるため、学校の利用条件を確認せずに公開しないでください。

Ctrlキーを押しながら複数セルを選択すると結合できます。セルを選択した状態でのコピー・貼り付け、矢印キーによる選択、Ctrl+Z / Ctrl+Yによる操作の取り消し・やり直しに対応しています。分割・結合後は内容を改めて確認してください。

現段階では自動で表全体を認識しません。セル範囲は手動で作成してください。入力値や網羅性を保証するValidator、配信用JSON、複数PDFの統合は未実装です。
