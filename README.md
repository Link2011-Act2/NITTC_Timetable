# SKTJF tools

鶴岡高専の時間割PDFを確認・修正し、SKTJFの配信データを作成するためのローカルツールです。現在は編集画面の開発途中で、SKTJFの検証・出力や配信にはまだ対応していません。作業ファイルを配信データとして公開しないでください。

## 起動

Node.js 22以上を用意し、このディレクトリで次を実行します。

```sh
npm ci
npm start
```

表示された `http://127.0.0.1:4173/` をブラウザーで開きます。サーバーはローカルからのみ接続を受け付けます。PDFと編集内容はブラウザー内で処理します。

## 編集

1. 年度を指定してPDFを開きます。PDF全体を解析し、読み取れた内容を右側の表に表示します。
2. 授業表では学期とクラスを選び、曜日・時限のセルを選択して内容を編集します。複数の授業も追加できます。
3. 隔週表では対象を選び、日付のセルでA/B、休日、行事、振替を編集します。解析されなかった週は追加できます。
4. 元のPDFと照らして確認してから「確認済み」にします。抽出された内容はすべて未確認です。
5. 「作業を保存」でPDFを含む作業ファイルを保存できます。「作業を開く」で続きから編集できます。作業ファイルにはPDF原本が含まれるため、学校の利用条件を確認せずに公開しないでください。

表のセルを選択した状態でのコピー・貼り付け、矢印キーによる選択、Ctrl+Z / Ctrl+Yによる操作の取り消し・やり直しに対応しています。旧バージョンの作業ファイルは内容を保持して開けますが、配置先が不明なため、自動では表に配置されません。

現段階の通常時間割の自動抽出は1年生の行を対象とし、教員・教室を科目名から自動分離しません。抽出結果は必ずPDFと照合してください。入力値や網羅性を保証するValidator、SKTJF出力、複数PDFの統合は未実装です。
