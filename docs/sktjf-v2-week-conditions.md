# SKTJF v2の授業週条件（検討中）

この文書は、授業週条件と授業機会のデータ契約を説明します。v1の既存配信形式は変更しません。

## 授業の条件

授業の `activeWeekRange` は `start`、`end`、`notation` を持ちます。`start` と `end` は両端を含む正の整数で、一方だけを `null` にできます。両方が `null` の場合は制限を設けず、`activeWeekRange` 自体を省略します。`notation` には資料の注記を保持します。配信する科目名から注記を除く場合、この条件と出典を失ってはいけません。

`weekCalendar` は、資料で日付と授業週の対応を直接確認できた場合の情報です。A/B区分とは別に扱います。日付が示されていない授業週は推測しません。

## 共通の授業機会

`weekSeries` は、同一の公式な授業機会に属する授業を `lessonIds` で指定します。`id`、`dayOfWeek`、`periods`、`cycle`、`sources` とともに保存します。`dayOfWeek` は月曜を1、日曜を7、`periods` は1から始まる時限番号です。隣接する時限であることだけを根拠に同一の授業機会とは判定しません。

対象授業の科目が途中で切り替わっても、共通の授業機会を基準に数えます。同一の機会に属する複数時限は1回です。条件を含む学生プロフィールで授業を絞っても、公式資料で確認された機会の時限構成を保持します。

任意の `countingPolicy` は、公式資料で確認した数え方を表します。資料の識別子とページ番号を `sources` に記録します。個人の休講や授業変更はこのポリシーへ混ぜません。

| フィールド | 意味 |
|---|---|
| `regularDayCounts` | 通常のA/B日を授業機会として数えるか |
| `holidayCounts` | 休日を授業機会として数えるか |
| `eventCounts` | 行事の種類ごとに授業機会として数えるか |
| `ordinaryPeriodCounts` | 個別指定がない対象時限を数えるか |
| `officialPeriodOverrides` | 公式資料に基づく日付・時限ごとの例外。時限は1から始まる |
| `confirmedNonTeachingDates` | 公式資料で授業がないと確認した日付 |
| `sources` | 数え方の根拠となる資料とページ |

真偽値の `null` や未指定の行事種類は未確定を意味し、`false` ではありません。平日の日付の記録が欠ける場合は、公式に授業がないと確認された日を除き未確定です。監修者が採用した方針により、通常の土曜日・日曜日は公式の授業・振替の指定がなければ数えません。指定のある週末はその内容を適用し、時限の指定だけで振替先などが不明な場合は未確定とします。未確定の機会がある場合、以降の回数も確定しません。連続時限の一部だけが実施される場合も、同じ機会として数えられる根拠がなければ未確定とします。

時間割の週数注記は、監修者が確定した仕様として、学期内に実施される共通授業枠の授業機会の回数で判定します。学期共通の `weekCalendar` と同じ値になるとは限らず、一方で他方を上書きしません。A/Bは曜日種別であり、通常授業の実施を単独で確定するものではありません。公式の祝日・休講・行事・試験・振替・授業変更を考慮し、授業が実施されない機会は数えません。試験時間割と行事予定を照合し、必要な公式情報が欠ける場合は未確定とします。

行事の記載だけでは通常授業を中止しません。対象の学年・時限の休講や変更が明示されなければ通常授業を維持します。定期試験・休業・明示された変更は別に扱い、日や時限への影響が確認できない定期試験は未確定とします。2026年11月25日の5Mは、監修者の採用仕様に基づきA/B表のBを保持しつつ中間試験として表示し、通常授業の回数には含めません。

## 配信と互換性

スキーマは `schema/sktjf-v2.schema.json`、manifestの検証はv1とv2の各形式に対応します。候補の検証は形式や出典参照の整合性を確認しますが、公式資料の解釈を証明するものではありません。授業機会が未確定の候補は配信出力できません。

2026年度後期は、監修者の確認により5M「機械設計製図II」は第1〜8回、「卒研」は第9回以降、4M「工学実験・実習III」は第1〜10回です。具体的な授業機会について公式情報が不足している日は未確定です。資料に基づかない値をポリシーに入力せず、対象授業を通常授業として無制限に配信しません。
