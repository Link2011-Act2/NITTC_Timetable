# 時間割PDFの下書き生成と監修からの注意点

2026年度の本科時間割について、エディターでの人間の監修結果を監修前の下書きと比較した。元PDFの文字配置と監修者が補った情報は別の根拠である。以下は次回の抽出時の確認方針であり、履修条件を推測して自動確定するためのルールではない。

## 複数クラスにまたがる授業

- 前期時間割PDF 1ページ、2年4クラスの月曜3限：「総合工学Ⅱ/デジタルデザイン応用工学Ⅱ」と一つの科目欄にまとめていた。監修後は「総合工学Ⅱ」（DD対象外）と「デジタルデザイン応用工学Ⅱ」（DD対象）に分割した。教員・教室は共通の原文を保持した。
- 後期時間割PDF 1ページ、同4クラスの火曜4限：「総合情報工学II/総合デジタルデザイン工学II」を同様に2授業へ分割し、DD属性を指定した。
- 原因は複数クラスを横断する枠の読み取りと、授業ごとの条件の未分離。今後はスラッシュを単純に1科目として扱わず、A/B・DD・別条件を区別して確認する。PDFだけで対象者が明示されない場合は監修を求める。

## 脚注による留学生用授業

- 前期時間割PDF 1ページ、3M火曜4限：「※1」を留学生向けの仮名として保存していた。監修後はA週「日本事情」、教員「石井」、教室「13Fゼミ室」に変更された。通常授業のB週「歴史Ⅱ」は保持された。
- 前期3I木曜1限ではB週の「※1」が「日本語I」、後期3I水曜2限ではB週の「※1」が「日本語II」に修正された。
- PDFの脚注は同時間帯の留学生用授業の存在を示すが、個々の科目名・教員・教室までは示していない。別資料や監修者の情報なしに名前を推測しない。監修による補完の資料は未特定であり、翌年度への流用はしない。

## 週数による変更と複数授業

- 後期時間割PDF 1ページ、5M水曜1限：元の下書きは「機械設計製図II」のみだった。監修後は「卒研（9週〜）」が同じ枠に追加された。水曜2限にも「機械設計製図II」が追加された。
- 元PDFの欄は科目と「卒研（9週〜）」が連続しており、授業の境界を見落とした。2026年度のシラバスと時間割を根拠に、監修者がこの枠の製図を第8週まで、卒研を第9週からと確認した。週番号と実日付の対応が未確認の場合は配信しない。
- 後期4M火曜3・4限の「工学実験・実習III（〜10週）」は、期間がある単一授業の例。注記を削除する場合も週数条件を失わないこと。

### 2026年度のシラバスとの照合

- [機械設計製図II](https://syllabus.kosen-k.go.jp/Pages/PublicSyllabus?department_id=10&from=curriculum&lang=ja&school_id=09&subject_id=0098&year=2022) はページ上で開講年度2026年度、5年機械コース、担当佐々木と記載し、後期1〜8週に授業内容、9〜16週に空欄がある。時間割の「卒研（9週〜）」と合わせ、監修者が当該2枠の切り替えを第8週終了後と確認した。週番号と実日付の対応は未確定。
- [工学実験・実習III](https://syllabus.kosen-k.go.jp/Pages/PublicSyllabus?department_id=10&lang=ja&school_id=09&subject_id=0074&year=2023) は2026年度、4年機械コースの通年科目であり、担当は五十嵐・荒船・和田・宍戸。時間割の科目・教員と整合する。各班の実験は別途配布のスケジュールによると説明されているため、これだけから週番号の具体的日付を推定しない。
- [卒業研究](https://syllabus.kosen-k.go.jp/Pages/PublicSyllabus?department_id=10&lang=ja&school_id=09&subject_id=0097&year=2022) は2026年度の5年機械コースの通年科目。シラバス全体の開設期間と、時間割上の水曜1・2限に付された「9週〜」を混同しない。
- シラバスのURL中の `year` は表示上の開講年度と異なる場合があるため、ページ内の開講年度・学科・科目・担当者を確認する。A/B表、祝日、学校行事、試験日をどのように授業週番号へ対応させるかは別資料を要する。
- 過去の[2016年度機械設計製図II](https://syllabus.kosen-k.go.jp/Pages/PublicSyllabus?department_id=02&lang=ja&school_id=09&subject_id=0188&year=2012)と[2018年度工学実験・実習III](https://syllabus.kosen-k.go.jp/Pages/PublicSyllabus?department_id=10&lang=ja&school_id=09&subject_id=0201&year=2015)には、それぞれ90分の授業2コマを週ごとに行い、後期の所定の実施回で完了する記載がある。科目の実施回を一単位とする解釈の補強にはなるが、2026年度における休日・行事・試験・休講・振替の扱いを直接示す資料ではない。
- 監修者は、学期内に実施される共通授業枠の機会を数える方式を採用した。連続2コマは1回とし、公式の祝日・休講・行事・試験・振替・授業変更を考慮する。個人の変更は回数に影響させない。公式情報が欠ける機会は未確定として扱う。
- 4M「工学実験・実習III」の2026年度シラバスは後期第9週まで授業内容が記載されているが、公式時間割の「〜10週」を優先し、監修者は第10回までの実施と確定した。この差異は、実施日がすべて確認済みであることを意味しない。
- 2026年度5M水曜1・2限は、公開行事予定表と時間割を踏まえた監修上の採用仕様として、10月7日・14日と12月2日を通常授業、11月25日を後期中間試験とする。これは実施実績の確認を意味しない。11月25日はA/B表のBも出典として保持し、試験日として表示して授業機会に数えない。
- 行事の記載だけを理由に通常授業を中止しない。対象学年・時限の休講や授業変更が明示されない場合は通常授業を維持し、定期試験、休業日、明示された休講、曜日振替は別途反映する。

## 教室・教員の補正

- 前期2B木曜3限：「物質実験」の教室「一般実験」は監修で空欄になった。前期4E木曜3限でも「ディジ信号」の教室が空欄になった。変更理由はPDFと監修記録だけでは確定できない。
- 欄をまたぐ文字の所属が不明なときは配置を確認し、推測で教員・教室を補わない。記載済みの複数名・複数教室は必要に応じて原文のまま保持する。

監修前後の授業内容・未分離状態に変化があったのは本科2〜5年の28コマ。確認済みフラグだけの変更やローマ数字の表記差は、この数に含めない。変更理由が資料から分からないものは未確定として扱う。
